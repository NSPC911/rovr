there are a couple integrations to improve rovr's functionality. enable and configure them in your `config.toml` file.

### zoxide

<InlineSVG src="/rovr/screenshots/plugin-zoxide.svg" alt="rovr's zoxide integration" />

[zoxide](https://github.com/ajeetdsouza/zoxide) allows you to zip around your filesystem, and can be integrated into rovr

<Tabs>
  <TabItem label="config.toml">
    <Code
      code={`[plugins.zoxide]\nenabled = true\nshow_scores = false  # include the zoxide scores in the results`}
      lang="toml"
      frame="code"
    />
  </TabItem>
  <TabItem label="keys.toml">
    <Code
      code={`[main]\n"z" = { action = "cd_zoxide", desc = "Jump to a directory" }`}
      lang="toml"
      frame="code"
    />
  </TabItem>
</Tabs>

### bat

to allow for more file previews, [bat](https://github.com/sharkdp/bat) can be used for its syntax highlighting capabilities.

```toml title="config.toml"
[interface]
show_line_numbers = true
[plugins.bat]
enabled = true
executable = "bat"
```

### fd

<InlineSVG src="/rovr/screenshots/plugins-fd.svg" alt="rovr's fd integration" />

uses [fd](https://github.com/sharkdp/fd) to search recursively in the current directory

<Tabs>
  <TabItem label="config.toml">
    <Code
      code={`[plugins.fd]\nenabled = true\nexecutable = "fd"\nrelative_paths = true\nfollow_symlinks = false   # search inside symlinks as well\nno_ignore_parent = false  # ignore .ignore files from parent directories\nsearch_hidden = false\ndefault_filter_types = ["file", "directory"]  # set default item filters (like \`file\`, \`directory\`, etc.)\ntimeout = 15  # set it to a reasonably high amount, searching without indexing takes time`}
      lang="toml"
      frame="code"
    />
  </TabItem>
  <TabItem label="keys.toml">
    <Code
      code={`[main]\n"f" = { action = "search_fd", desc = "Search for files" }`}
      lang="toml"
      frame="code"
    />
  </TabItem>
</Tabs>

### rg

<InlineSVG src="/rovr/screenshots/plugins-rg.svg" alt="rovr's rg integration" />

uses [ripgrep](https://github.com/BurntSushi/ripgrep) to search inside files

<Tabs>
  <TabItem label="config.toml">
    <Code
      code={`[plugins.rg]\nenabled = true\nexecutable = "rg"\ncase_sensitive = true\nno_ignore_parent = false  # ignore .ignore files from parent directories\nfollow_symlinks = false\nsearch_hidden = false\ntimeout = 60  # set it to a much higher amount, content searching takes time`}
      lang="toml"
      frame="code"
    />
  </TabItem>
  <TabItem label="keys.toml">
    <Code
      code={`[main]\n"\\" = { action = "search_rg", desc = "Search file contents" }`}
      lang="toml"
      frame="code"
    />
  </TabItem>
</Tabs>


### poppler

<img src="/rovr/screenshots/preview-pdf.png" alt="rovr's poppler integration" />

uses [poppler](https://poppler.freedesktop.org) to preview PDF files

```toml title="config.toml"
[plugins.poppler]
enabled = true
threads = 1
use_pdftocairo = false  # use pdftocairo instead of pdftoppm (may help performance)
poppler_folder = ""     # where the poppler tools are installed (auto detected).
pdf_batch_size = 2
```

### file(1)

uses the [`file`](https://darwinsys.com/file) command as an alternative to puremagic if it fails to detect a file's type.

rovr automatically detects `file` in your `PATH`, or you can set the `YAZI_FILE_ONE` or `ROVR_FILE_ONE` (higher priority) environment variables to specify a custom path.

```toml title="config.toml"
[plugins.file_one]
enabled = false
get_description = true  # whether to get extra file description from `file -b <file>` (default: `true`)
```

### resvg

uses the [`resvg_py`](https://github.com/baseplate-admin/resvg-py) module to provide svg image preview support

this cannot be disabled, as it doesn't depend on the resvg binary, but rather the maturin binding itself.

no configuration is available for this.
