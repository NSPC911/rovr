## everything you need, without leaving the terminal

rovr brings file management, rich previews, tabs, archives, and configurable
workflows together in one polished interface.

## visual where it helps, fast where it matters

rovr is built with Python and Textual for Windows, macOS, and Linux. It is
designed for people who want the speed of a terminal workflow without giving up
discoverability or a good-looking interface.

## ready to take it for a spin?

Try rovr without installing it permanently:

```sh
uvx rovr
```
