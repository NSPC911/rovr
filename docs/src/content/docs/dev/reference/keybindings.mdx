## Quick start

rovr lets you inherit from one of three built-in keybinding sets: `base`, `vim`, or `sane`.

If `keys.toml` is empty or does not exist, rovr will use the older, unsupported keybindings (not the `base` set, the one defined in `config.toml`)

## Action syntax

Assign an action to a key under a context in `keys.toml`. A binding may be an action string or
an inline table with a required `action` and optional `desc`:

```toml
[main]
"ctrl+t" = "tab_new"
"?" = { action = "show_keybinds", desc = "Show keybindings" }
# yes function-like syntax is supported, for supported literal values
"1" = "activate_tab(0)"
# check https://docs.python.org/3/library/ast.html#ast.literal_eval
# obviously dont pass anything stupid

[file_list]
"ctrl+c" = "copy.to_rovr"
```

Both forms dispatch actions identically. `desc` is shown in the keybindings screen; when it is
omitted, the action string is shown instead. Bindings for the same action in one context are
grouped together, so only one of them needs a description:

```toml
[global]
"q" = { action = "app.quit", desc = "Quit rovr" }
"ctrl+q" = "app.quit"
```

The name of a Python method such as `action_tab_new` becomes `tab_new` in `keys.toml`.
Arguments use Textual's action syntax: `cycle_tab(-1)`, `cursor(1)`, or `sort_order.set("modified", True)`.

Actions without a prefix run on the owner of the active context. The following namespaces can target another object explicitly:

| Namespace       | Target                            | Example        |
| --------------- | --------------------------------- | -------------- |
| `app`           | The rovr application              | `app.quit`     |
| `screen`        | The currently active screen       | `screen.exit`  |
| Primary context | The mounted owner of that context | `copy.to_rovr` |

Primary context namespaces include `copy` and `sort_order`. Prefer an unqualified action when
the action belongs to the context containing the binding.

## Context resolution

rovr checks contexts from the focused widget outward. The first matching action wins. Specific
contexts are checked before reusable contexts, such as `file_list` before `lists` and
`search_input` before `inputs`.

`main` is available only while the main screen is unobstructed. `global` is checked separately
for application-wide bindings, including while a modal is open. Set an inherited key to `noop`
to consume it without running an action.

```toml
inherit = "vim"

[file_list]
"q" = "noop"

[global]
"ctrl+q" = "app.quit"
```

## Application contexts

### `global`

Use `global` sparingly for actions that must work regardless of the active screen.

| Action                | Description                        | Example                            |
| --------------------- | ---------------------------------- | ---------------------------------- |
| `app.quit`            | Quit rovr.                         | `"ctrl+q" = "app.quit"`            |
| `app.command_palette` | Open Textual's command palette.    | `"ctrl+p" = "app.command_palette"` |
| `app.suspend_process` | Suspend rovr on supported systems. | `"ctrl+z" = "app.suspend_process"` |

### Running commands

You can run shell/argv commands using the app context. The `run_command` action runs a command as an argv list,
while `run_shell` runs a command through the shell. Both actions accept an optional `run_type` arg (not kwarg)
that can be one of ("suspend", "background", "orphan")

- suspend: hides rovr's ui and runs the command in the foreground, returning to rovr when it exits
- background: runs the command in the background, returning to rovr immediately. it will stop process when exiting
- orphan: runs the command detached, rovr cannot read stdout/stderr/exit code, and will not stop the process on exit

| Action        | Description                                   | Example                                                  |
| ------------- | --------------------------------------------- | -------------------------------------------------------- |
| `run_command` | Run a argv command in the current directory.  | `"@" = 'run_command(["echo", "hello world"], "orphan")'` |
| `run_shell`   | Run a shell command in the current directory. | `"ctrl+@" = 'run_shell("echo hello world", "orphan")'`   |

### `pinned_sidebar`

Uses all [`lists`](#lists) actions and adds `focus_search`, which focuses the pinned-folder
search input.

### `clipboard`

Uses all [`lists`](#lists) actions. It also supports `delete` to remove the highlighted
clipboard entry, `toggle_all` to select or clear all entries, and the range-selection actions
described below.

### `processes`

Uses all [`scroll`](#scroll) actions. `delete` clears completed and failed processes.

### `preview` and `metadata`

Both support the [`scroll`](#scroll) actions. `preview` additionally provides `up`, `down`,
`page_up`, `page_down`, `home`, and `end` for navigating rendered content.

## Reusable widget contexts

### `lists`

The fallback context for option and selection lists. It is shared by file lists, popup menus,
search results, archive options, trash entries, and other selectable lists.

| Action               | Description                              | Example                         |
| -------------------- | ---------------------------------------- | ------------------------------- |
| `cursor(offset)`     | Move by a number of enabled items.       | `"j" = "cursor(1)"`             |
| `cursor_page(pages)` | Move by a number of visible pages.       | `"pagedown" = "cursor_page(1)"` |
| `first`              | Move to the first item.                  | `"home" = "first"`              |
| `last`               | Move to the last item.                   | `"end" = "last"`                |
| `select`             | Activate or toggle the highlighted item. | `"enter" = "select"`            |

Selection-list contexts also provide `select_cursor(offset)` and `select_cursor_page(pages)`
for extending a selection. These include `file_list`, `clipboard`, `file_search_filters`,
`content_search_filters`, `archive_types`, `archive_compression`, and `trash_list`.

The following primary contexts inherit `lists`: `file_list`, `pinned_sidebar`, `clipboard`,
`popup_list`, `file_list_menu`, `file_list_submenu`, `search_results`, `special_option_list`,
`file_search_filters`, `content_search_filters`, `keybind_list`, `archive_types`,
`archive_compression`, `paste_drop_list`, and `trash_list`.

### `inputs`

and `modal_input_field`.

| Action              | Description                        | Example                                 |
| ------------------- | ---------------------------------- | --------------------------------------- |

| `cursor_right`      | Move right by one character.       | `"right" = "cursor_right"`              |
| `cursor_left_word`  | Move left by one word.             | `"ctrl+left" = "cursor_left_word"`      |
| `cursor_right_word` | Move right by one word.            | `"ctrl+right" = "cursor_right_word"`    |
| `home`              | Move to the start of the input.    | `"home" = "home"`                       |
| `end`               | Move to the end of the input.      | `"end" = "end"`                         |
| `delete_left`       | Delete the character to the left.  | `"backspace" = "delete_left"`           |
| `delete_right`      | Delete the character to the right. | `"delete" = "delete_right"`             |
| `delete_left_word`  | Delete the word to the left.       | `"ctrl+backspace" = "delete_left_word"` |
| `delete_right_word` | Delete the word to the right.      | `"ctrl+delete" = "delete_right_word"`   |
| `delete_left_all`   | Delete everything to the left.     | `"ctrl+u" = "delete_left_all"`          |
| `delete_right_all`  | Delete everything to the right.    | `"ctrl+k" = "delete_right_all"`         |
| `select_all`        | Select the entire value.           | `"ctrl+a" = "select_all"`               |
| `copy`              | Copy selected text.                | `"ctrl+c" = "copy"`                     |
| `cut`               | Cut selected text.                 | `"ctrl+x" = "cut"`                      |

| Action         | Description              | Example                           |
| -------------- | ------------------------ | --------------------------------- |

## Menu contexts

### `copy_menu`

| Action                   | Description                                  |
| ------------------------ | -------------------------------------------- |
| `copy.to_rovr`           | Copy selected files to rovr's clipboard.     |
| `copy.highlighted`       | Copy the highlighted path.                   |
| `copy.to_system_clip`    | Copy selected paths to the system clipboard. |
| `copy.current_directory` | Copy the current directory path.             |

### `sort_menu`

The actions `sort_order.name`, `sort_order.extension`, `sort_order.natural`,
`sort_order.size`, `sort_order.created`, and `sort_order.modified` select a sort method.
`sort_order.descending` toggles descending order.

The lower-level action `sort_order.set(method, descending)` accepts a method name and a Boolean:

```toml
[file_list]
"alt+m" = "sort_order.set('modified', True)"
```

## Search and modal contexts

### `filter_modal`

Shared by `file_search`, `content_search`, `directory_jump`, `theme_chooser`, and `keybinds`.

| Action               | Description                    | Example                         |
| -------------------- | ------------------------------ | ------------------------------- |
| `exit`               | Close the modal.               | `"escape" = "exit"`             |
| `cursor(offset)`     | Move through results.          | `"down" = "cursor(1)"`          |
| `cursor_page(pages)` | Move through results by pages. | `"pagedown" = "cursor_page(1)"` |

The `keybinds` context also supports `focus_search`. `shell_exec` supports `cycle_mode`.

### Confirmation contexts

| Context             | Actions                                                   |
| ------------------- | --------------------------------------------------------- |
| `delete_files`      | `trash`, `delete`, `cancel`                               |
| `trash`             | `restore`, `purge`, `empty`, `cancel`                     |
| `filename_conflict` | `overwrite`, `rename`, `skip`, `cancel`, `dont_ask_again` |
| `file_in_use`       | `retry`, `skip`, `cancel`, `toggle_dont_ask_again`        |
| `yes_or_no`         | `yes`, `no`, `dont_ask_again`                             |
| `paste_drop`        | `copy`, `move`, `cancel`                                  |

These actions apply only while their corresponding modal is open.

## Finding the key names

Run `rovr --show-keys` to display the key name that will be used.
