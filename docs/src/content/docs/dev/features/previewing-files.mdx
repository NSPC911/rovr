## Supported preview types

rovr supports a wide range of file types for previewing. the following are the main categories of files that can be previewed:

### `text` files

<InlineSVG src="/rovr/screenshots/preview-file.svg" alt="file preview" />

plain text files are displayed in a text area with syntax highlighting. the language is determined by the file extension. `rovr` supports a wide range of languages.

### `details` of unknown/binary files

<InlineSVG src="/rovr/screenshots/mime-type.svg" alt="mime type detection" />

mime types are automatically obtained using [puremagic](https://pypi.org/project/puremagic) to give you a more accurate information of the file's type. If you additionally have `plugins.file_one` enabled with `plugins.file_one.get_description`, you can view extra information, like how many sections, what type, etc.

### bat plugin

<InlineSVG src="/rovr/screenshots/preview-file-bat.svg" alt="file preview with bat" />

if you have [`bat`](/rovr/dev/features/plugins#bat) installed and enabled in the `rovr` config, it will be used to display text files with syntax highlighting for much more languages and theming. uses the same id as `text`

### `image`s

![pdf preview](/rovr/screenshots/preview-image.png)

`rovr` can display images directly in the terminal. refer to the [image previews](/rovr/dev/features/image-previews) guide for more details on terminal compatibility and configuration.

rovr's image preview is based on [PIL](https://pillow.readthedocs.io/en/stable/), so it supports a wide range of image formats, including `.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.tiff`, and more. \
For unsupported image formats, if imagemagick is configured, it will automatically be used to convert the image to a supported format for previewing.

### `folder`s

<InlineSVG src="/rovr/screenshots/preview-folder.svg" alt="folder preview" />

when a folder is selected, the preview panel will show a list of the files and folders inside it, allowing you to see the contents without navigating into it.

<Aside type="tip">
  If you focus on the folder preview, you can navigate in there to open files and folders, letting you skip actually cd-ing into it!
</Aside>

### `archive`s

<InlineSVG src="/rovr/screenshots/preview-archive.svg" alt="archive preview" />

for archive files (like `.zip`, `.tar.gz`, `.rar`), rovr will display a list of the files and folders contained within the archive.

### `pdf` with poppler

![pdf preview](/rovr/screenshots/preview-pdf.png)

for pdf files, rovr makes use of [poppler](https://poppler.freedesktop.org). you can also scroll through the pdf with your mouse (scrollbars are unavailable for now) or use your keyboard to navigate it.

### svg with `resvg`

{/* no image for now, please TODO: find a way to reduce the size of the PIL object, it being large destroys the performance of the preview panel */}
rovr makes use of [resvg-py](https://pypi.org/project/resvg-py) to render svg files, so you don't need resvg installed on your system -- it automatically previews the svg file for you without any setup

### `font`s

![font preview](/rovr/screenshots/preview-font.png)

for font files (like `.ttf`, `.otf`), rovr will display a preview of the font. you can customise the text used in the preview if you want to test extra things

### `video`s with ffmpeg

it will display the first frame of the video as an image, and you can use your keyboard to navigate through the video, 1 second (or 10 seconds) at a time

## Custom preview rules

You can change the file type to preview association by modifying the `[settings.preview_rules]` section in your `config.toml`

If your mime type is accurate enough (like `image/png`), you can omit the check and use the mime type only:

```toml
[settings.preview_rules]
"image/png" = "image"
```

the value is any of the default previewers mentioned above in an inline codeblock. Only one is allowed per mime type, but you can add fallbacks with more wildcard mime types

However, in the case of vague mime types like `application/gzip`, if you want to preview `.svgz` files as an svg instead of a failed archive file, you can use the following rule:

```toml
[settings.preview_rules."application/(x-)?gzip"]
default = "archive"
extensions = { svgz = "resvg" }
```

In the above example, we are telling rovr that for files with mime type `application/gzip` and `application/x-gzip`, to use archive by default, except if the file ends with `.svgz`, and in that case, use the svg renderer

The full syntax for the preview rules is as follows:

```toml
[settings.preview_rules."mime/type"]
default = "previewer_name"
extensions = { "ext1" = "previewer_name1", "ext2" = "previewer_name2" }
```

## Custom previewers

You can also create your own previewers for any file type.

For example, if you want to preview `.md` files using [`glow`](https://github.com/charmbracelet/glow), you can add the following to your `config.toml`:

```toml
[settings.previewers]
"glow" = { command = ["glow", "--style", "dark", "%h"], file = "__stdout__", type = "text" }

[settings.preview_rules."text/plain"]
default = "text"
extensions = { "md" = "glow" }
```

rovr will now use `glow` to preview `.md` files instead of `bat` (or rovr's built-in text highlighter).

<Aside type="note">
  This preview is also cached, so if you have a large markdown file, it will not be re-rendered every time you open it. You can also use the `--style` option to change the theme of the preview.
  <br/>However, this also means that since files are not incrementally rendered, the preview will take some time to load for larger files.
</Aside>

For images, you can have `type = "image"` for your custom previewer.

An example of this is to preview `.html` files. You can use helium (or any chromium browsers) to do so, just add the following to your `config.toml`:

```toml
[settings.previewers.helium]
command = ["helium", "--headless", "--no-first-run", "--disable-gpu", "--user-data-dir=%tmpdir", "--screenshot=%file", "%h"]
# create a temporary file with the .png extension for the screenshot
file = "%temp.png"
type = "image"

[settings.preview_rules."text/html"]
default = "text"
extensions = { html = "helium", htm = "helium" }

[settings.preview_rules."text/plain"]
default = "text"
extensions = { html = "helium", htm = "helium" }
```

`%file` is the path configured by `file`, so helium writes the PNG that rovr reads. `%temp` keeps the source extension; `%temp.png` uses `.png` instead. This also works with other output extensions, provided your previewer can produce and rovr can display them. `%tmpdir` gives each run its own temporary browser profile and is removed when the command finishes.

<Aside type="note">
  A launcher-supplied `--user-data-dir` can override the temporary profile above.
  <br/>On Windows with <a href="https://scoop.sh">scoop</a>, it will force a profile directory, you should instead direct it to the underlying `chrome.exe` path
</Aside>

<br />
The `%temp` is the path to a temporary file that will be created for the
previewer to write to. You can modify the file extension by including it in the
`%temp` variable, like `%temp.png`. The temporary file will be deleted after the
preview is displayed.

The full syntax for the custom previewers is as follows:

```toml
[settings.previewers."previewer_name"]
command = ["command", "arg1", "arg2", "%h"]
file = "%temp(.ext) | __stdout__ | __stderr__ | /path/to/file"
type = "text | image | pdf"
on_nonzero_exit = "details"  # or any default available previewers mentioned above
```

Supported Expansions:
- `%h` - path to the file being previewed
- `%rh` - realpath to file being previewed
- `%nh` - name of file being previewed
- `%rnh` - realpath name of file being previewed
- `%cwd` - current working directory
- `%rcwd` - realpath to current working directory
- `%temp` - path to a temporary file that will be created for the previewer to write to. \
  You can include a file extension in the variable, like `%temp.png`. The temporary file will be deleted after the preview is displayed.
- `%tmpdir` - path to a temporary directory that will be created for the previewer to write to. \
  The temporary directory will be deleted after the preview is displayed.

#### List of cool previewers

Helium and Glow are mentioned above, here is a few more previewers that you can use:

- [libreoffice](https://www.libreoffice.org/): for previewing office documents like `.docx`, `.xlsx`, `.pptx`
Paste the following script somewhere accessible and add it to your config.toml as a previewer:

<Tabs>
  <TabItem label="bash/zsh">

```bash frame="none"
#!/usr/bin/env bash
set -e
to_preview=$1
outfile=$2
write_to=$(dirname "$outfile")
pdf="$write_to/$(basename "${to_preview%.*}").pdf"
if ! libreoffice --headless --convert-to pdf "$to_preview" --outdir "$write_to"; then
    exit 1
fi
mv -f -- "$pdf" "$outfile"
```

Then `chmod +x /path/to/libreoffice-preview.sh` to make it executable.

  </TabItem>
  <TabItem label="powershell">

```powershell frame="none"
param(
    [Parameter(Mandatory = $true)][string]$ToPreview,
    [Parameter(Mandatory = $true)][string]$Outfile
)
$writeTo = Split-Path -Parent $Outfile
if (-not $writeTo) { $writeTo = '.' }
& libreoffice --headless --convert-to pdf $ToPreview --outdir $writeTo 2>&1
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
$pdf = Join-Path $writeTo (([IO.Path]::GetFileNameWithoutExtension($ToPreview)) + '.pdf')
Move-Item -LiteralPath $pdf -Destination $Outfile -Force
```

  </TabItem>
</Tabs>
Then add the following to your config.toml:

```toml
[settings.previewers.libreoffice]
# powershell
command = ['powershell', '-NoProfile', '-File', '/path/to/libreoffice-preview.ps1', '%h', '%file']
# bash
# command = ['/path/to/libreoffice-preview.sh', '%h', '%file']
file = "%temp.pdf"
type = "pdf"

[settings.preview_rules]
"application/(vnd\\.)?openxmlformats-officedocument.*" = "libreoffice"
"application/oasis.opendocument.*" = "libreoffice"
"application/ms-*" = "libreoffice"
"application/msword" = "libreoffice"
```

- [pixelorama](https://pixelorama.org): for previewing `.pxo` files, frames arent supported, it's just a static image previewer
```toml
[settings.previewers.pixelorama]
command = ['pixelorama', '--headless', '--quit', '--', '%h', '--export', '--output', '%file']
file = "%temp.png"
type = "image"
[settings.preview_rules."application/zip"]
default = "archive"
extensions = { pxo = "pixelorama" }
```
